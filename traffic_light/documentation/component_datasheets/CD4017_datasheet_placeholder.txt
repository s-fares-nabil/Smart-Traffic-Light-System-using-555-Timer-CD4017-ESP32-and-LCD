Pinout Description (for traffic light application):
- Clock Input (Pin 14): Receives pulses from 555 timer
- Clock Inhibit (Pin 13): Usually tied to ground
- Reset (Pin 15): Connected to Q10 (Pin 11) for automatic reset after 10 counts
- Decoded Outputs (Pins 1-7, 9-11): Q0-Q9 (Pin 15 is not an output)

  * Q5-Q9: Green LED phase (5 steps)
  * Q10 (Pin 11): Triggers reset (connected to Pin 15)
